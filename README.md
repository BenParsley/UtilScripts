# UtilScripts
A collection of custom tools and scripts.

## Tools

### 1. Hardware Breakdown
Displays a quick summary of your system's hardware specs (CPU, RAM, GPU, storage, and peripherals).
- **sourcecode**: `.\HardwareBreakdown\hardwareBreakdown.ps1` 
- **executable**: `.\HardwareBreakdown\HardwareBreakdown_v1.1.exe`

### 2. Windows Update Checker
Checks if a specific Windows update (KB number) is installed on your computer.
- **sourcecode**: `.\WindowsUpdateChecker\WindowsUpdateCheck.ps1`
- **executable**: `.\WindowsUpdateChecker\WindowsUpdateCheck.exe`

## Requirements
- Windows 10/11
- Run PowerShell as Administrator for best results
